# Polaris デザイン仕様「一点の光」

前提: `docs/product.md`（データモデル・ルール・構成）。この文書は見た目と振る舞いだけを決める。仕様の意図は変えない。

## 0. 審査

| 案 | 問題解決 | 邪魔にならなさ | 7軸 | AIっぽさの無さ | 実現性 | 平均 |
|---|---|---|---|---|---|---|
| 1 paper（静かな付箋） | 8 | 8 | 8 | 7 | 8 | 7.8 |
| 2 ネイティブのピル | 7 | 7 | 7 | 6 | 6 | 6.6 |
| **3 star（一点の光）** | **9** | **9** | **8** | **9** | **7** | **8.4** |

- **3を土台にした理由**: 無彩色の付箋に明朝の北極星を1文だけ置き、一時的なメッセージは最下段の「声の行」1か所に優先順位付きで出す。
- **案1から移植**: 寄り道の「5分だけ」、隠しているあいだの簡易寄り道表示、明朝に New York を組み合わせる書体カスケード、メニューバー1行目の北極星。
- **案2から移植**: 展開を画面の中心側へ向けること、クリックで展開を固定すること、⌥を押しているあいだだけクリック透過を解除すること、クイック編集パネル。
- **採らなかったもの**: 案1のクリーム地（AI_SLOP 2章に抵触するため、無彩色の `surface` にした）。案2の全面ティント（薄色塗り）、最大サイズ固定パネル＋自前 hit-test（壊れやすい）、17対13pt の弱い階層。案3の「支度シートを付箋そのものが変形して出す」方式（nonactivating パネルでは key の扱いが複雑になるので、別パネルにした）

---

## 1. コンセプト

- 無彩色の付箋に、明朝の大きな1文を置く。常駐時の主役は北極星だけ。
- 補足と操作は開いたときに出す。寄り道・MCP の一時メッセージ・北極星の達成や予約の知らせは声の行に出す。
- 用語は「北極星」「控え」「これまで」。窓と入口は「北極星の一覧」に統一する。
- 背景の素材感、ライト／ダーク、Increase Contrast、Reduce Motion を保つ。

### 用語集（UI ではこの語を使う）

| 語 | 指すもの | 使い方 |
|---|---|---|
| 北極星 | 今日いちばん大事な1文 | 「北極星を書き換える」 |
| 控え | 次に選ぶ北極星 | 「控えに入れる」「これにする」 |
| これまで | 達成・手放した北極星の記録 | 「控えに戻す」 |
| 寄り道 | avoidApps が前面に来ること | 内部用語 |
| 声の行 | 付箋の最下段の1行 | 内部用語 |

## 2. 状態ごとのレイアウト

### 常駐

幅304pt、左右20pt、上下16pt、角丸16pt。北極星は最大2行。達成ボタンと一覧の行は出さない。北極星が空なら「北極星を設定する」だけを入口にする。
期限は展開中、または期限を過ぎているときに北極星の下へ出す。通常のモード表示は開いたときだけ。

### 展開

```
決済APIの移行を今日中に        [✓]
本番へ出す
あと4日
☷ 北極星の一覧  次 〇〇 ほか 2 › [+]
▣ 仕事の日                      ⚙
```

- 1段目は上揃えの HStack。左の北極星は伸縮し最大4行、右の ✓ は `SmallButtonStyle(outlined: true)`、読み上げは「達成した」、案内は `Hint.starAchieve`。今日が空で控えがあるときは「これにする」。閉じた付箋には出さない。
- 北極星の期限の下に8pt空け、一覧の入口を常設する。左のボタン全体で一覧を開く。`list.bullet`＋「北極星の一覧」＋控えがあれば `MetaText` の「次 〇〇 ほか n」＋`chevron.right`。補足が長ければ末尾を省略する。右端の＋は別のボタンで控えへの入力欄を開く。
- 控えが空でも一覧の行は出す。控えが20件なら＋は出さない。入力中も一覧への入口を残す。
- 下段にモードの切り替えと歯車を置く。声の優先順位は寄り道→一時的な知らせ→banner→モード。
- 今日の北極星はクリックで一覧、ダブルクリックでその場の編集。右クリックと VoiceOver から達成・手放すにも届く。

### 朝の支度

付箋とは別の key になれる borderless な floating `NSPanel`。幅400pt、余白24pt、角丸18。付箋の隅を起点に画面中心側へ出す。自動で出したときは key にせず、クリックかメニューバーから開いたときに key にする。モード→北極星の2ステップで、進捗は「1 / 2」「2 / 2」。

1. 「今日はどんな日？」。モードを縦に並べ、数字キーまたは上下キーで選ぶ。「北極星を書く」で進む。
2. 「今日いちばん大事なことを1文で」。明朝の入力欄、補足「1文で書けないなら、まだ絞れていない。」、未達なら昨日の北極星を引き継ぐ入口。「この北極星で始める」で保存して閉じる。空なら主ボタンを無効にし「北極星なしで進む」を出す。

⌘←で戻る。⎋は入力済みの北極星を保存して閉じる。

### クイック編集

⌃⌥Pで北極星だけの入力欄を開く。幅400pt、入力欄はr6、hairline 1pt、フォーカス枠2pt。
⏎で保存、⌥⏎で今日を変えず控えへ入れる、⎋で閉じる。控えが満杯なら入力を残す。

### 北極星の一覧

窓のタイトルは「北極星の一覧」。今日の北極星、控え、これまでを扱う。控えはドラッグで並べ替え、これにする・削除・期限・予約を設定できる。VoiceOverには上へ・下へ等の操作も出す。これまでには達成／手放した記録と期間を出し、控えに戻せる。最新1件より前はたためる。

### メニューバーと設定

表示／非表示のすぐ次に「北極星の一覧… ⌃⌥L」を置く。北極星の書き換え、朝の支度、モード、隅、設定、終了は残す。
設定は表示・モード・ショートカット・起動・MCPの1画面。既存のショートカット欄にも一覧を開く⌃⌥Lを載せる。

### 寄り道を検知したとき

付箋の大きさ・位置・不透明度・北極星は**変えない**。

```
│  『遅いインターネット』を3章まで読む    │
│ ↕16                                │
│  読書の日。戻る？ [Slackを隠す] [5分]  │ 声の行は1行（高さ16）のまま。voiceEmphasis ink
│                                    │ smallButton h24 r6 は上下にはみ出す。1つ目は ink の枠、2つ目は文字だけ
```

- 「{App}を隠す」は `NSRunningApplication.hide()` を呼ぶだけにする。終了もブロックもしない。隠すと直前のアプリが前面に戻る
- 「5分だけ」はそのアプリについて5分間出さない（仕様の5分抑制を、自分で選べるようにしたもの）
- 何も押さなくても、前面アプリが変わるか12秒経ったら元の声の行に戻す
- 同じアプリで連続して出すのは5分に1回まで（仕様どおり）
- **⌃⌥H で隠しているとき**: 付箋と同じ隅に、北極星と声の行だけの簡易パネル（幅304、ボタンなし、クリック透過）を12秒出す。見たくない日ほど寄り道しやすいので、ここは止めない
- **「15分だけ隠す」中**: 何も出さない（休憩を自分で選んだため）
- クリック透過中: 声の行だけ替え、ボタンは出さない

### MCP からの banner

声の行に出す。優先順位は **寄り道 > 一時的な知らせ > banner > モード表示**。同時に出すのは1件だけで、下位のものは上位が消えるまで待つ。

モード表示の「{glyph} {mode} ⌃⌄」は押すとモードの一覧を出し、その場で切り替えられる（今のモードにチェック）。透過中は押せない。

```
│ ↕16                                │
│  PR終わったよ、北極星に戻ろう · Claude… × │ 常駐中は1行。text は ink、「· {client}」は ink2、末尾を省略
│  （展開中だけ 全文2行 ＋「{client} から」meta ink2）      │
```

- 北極星より上には出さない。背景も塗らない。バッジ・色・音も付けない
- × は20pt、当たり判定24×24。`expiresAt` が来るか × を押したら、モード表示に戻す
- banner が出ているあいだにモードが替わったら（メニュー・支度・MCP のどれでも）、「一時的な知らせ」と同じ段で「{glyph} {mode label}に切り替えた」を4秒出してから banner に戻す。glyph と位置はモード表示と同じにし、文字だけ ink にする。モードを常設する2つ目の場所は作らない（声の行を1か所に保つため）。モード表示が見えているときは行そのものが替わるので出さない

### クリック透過中（既定）

```
┌──────────────────────────────────────┐
│ ⠿ 決済APIの移行を今日中に本番へ出す     │ ⠿ = つまみ（縁の内側）
└──────────────────────────────────────┘
```

- 閉じた付箋は `ignoresMouseEvents = true` で、後ろの窓をそのまま触れる。ホバーしても展開しない。設定の「閉じた付箋のクリックを通す」と ⌃⌥T で切り替える（既定はオン）
- 付箋の画面中央側の縁の内側（右の隅なら左端、左の隅なら右端から4）に、14×48 のつまみを重ねる（端から3）。左右の余白20に収まり、文字まで3空く。クリックを通すかは窓ごとにしか決められないので、つまみは付箋より1段上の小さな窓にする。縦位置は閉じたときの付箋の真ん中で、開いても動かさない。角丸の帯に `hoverFill`、2列×3段の点（⌀3、ink2）。ホバーで `pressFill` にし、点を開閉の矢印（閉じていれば ↖↘ `arrow.up.left.and.arrow.down.right`、開いていれば `arrow.down.right.and.arrow.up.left`、10pt bold ink）に替える。カーソルは openHand。Increase Contrast では縁に `HighContrast.border`
- つまみはホバーでは開かない。押すと開き（開いていれば畳む）、3pt 以上ドラッグすると付箋ごと動かし、離すと付箋と同じように隅へスナップする
- つまみにホバーすると、付箋の外の中央側に吹き出し「クリックで開く・ドラッグで動かす」（開いていれば「クリックで閉じる・…」）。吹き出しはクリックを通す別の窓に出す
- つまみで開いているあいだは普通の付箋と同じに触れる。カーソルが付箋の外へ出たら畳み、透過に戻る
- ⌥ を押しているあいだも触れる（判定方法は6章）

### 北極星の控えと振り返り

北極星は今日に1つ。ほかは「控え」に並べておき、今日のものを終えたら先頭が1段目に上がる。主役は1つのまま、次を思い出させるのは上がってきた明朝の1文に任せる。

- 常駐（collapsed）には何も足さない
- 北極星を1回押すと北極星の窓を開く（期限・予約・控え）。2回押すとその場で書き直す
- 期限があれば、展開中だけ北極星の下（間隔 xs）に meta で「{M/d H:mm}まで・あと{n}時間」（1日以上なら「あと{n}日」、時刻のない期限は「{M/d}まで」）。過ぎたら「…・{n}時間超過」を danger で、閉じていても出す
- 北極星を右クリック:［達成した］［手放す］。VoiceOver の操作にも同じ2つを付ける
- 達成したら、付箋の外まで紙吹雪と星を弾けさせる（2.2秒、透明でクリックを通す窓を一瞬だけ重ねる）。最初の0.55秒は起点に光の輪。音は「Hero」。Reduce Motion のときは動きを出さず音だけ。設定で演出と音を切れる
- 予約（`startsAt`）の時刻が来た控えは、30秒以内に今日の北極星へ上がる。今日の北極星は控えの先頭へ戻す。隠していても付箋を出し、声の行に「「{title}」の時間になった」を10秒出す
- 終えたら、1段目は控えの先頭に替わり、声の行に「「{title}」を達成。［取り消す］」（手放したときは「を手放した。」）を6秒出す。取り消すと、終えた北極星が今日に戻り、繰り上がった分は控えの先頭へ戻る。読み上げは「{title}を達成した。次の北極星は{next}」
- クイック編集の北極星欄で ⌥⏎ は「控えに入れる」（今日の北極星は変えない）。控えが満杯なら入力を残す
- 北極星の一覧（幅480、縦は画面に収まる高さで固定してスクロール。設定と同じく、まとまりを白い面 `GroupCard` に載せる）:
  - 今日の北極星: 明朝で全文、「{M/d}から」、［手放す］［達成した］。下に「期限」の行（決めていなければ［決める］で1週間後の18:00、決めたら日時の欄と ⊗）
  - 控え: 行は上下に並べ替えるボタンを出さず、ドラッグで並べ替える。掴んだ行は `raised` の面と影で浮かせて指に付け、ほかの行は落ちる先を空けるようにずれる。離したときに1回だけ保存する。システムのドラッグ＆ドロップは使わない（取り消しの合図が来ないことがあるため）。ホバー中だけ左に ≡、右に［これにする］とゴミ箱（24×24、ホバーで danger）。行を押すと、その下に「期限」と「今日の北極星にする日時」（予約。［決める］で翌朝9時）の欄が開く。行の下に meta で期限と「⏰ {M/d H:mm}に今日の北極星へ」。VoiceOver には「上へ」「下へ」「これにする」「削除」の操作を付ける。下に入力欄と［控えに入れる］
  - これまで: 新しい順。最新の1件だけ出し、2件目からは「ほか{n}件を見る ⌄」でたたむ。達成は ★（star）と ink、手放したは ◌ と ink2。meta で「達成 · 9/28 → 9/30（3日）」、［控えに戻す］

### 3-2. タイポグラフィ `PolarisTheme.Typography`

| 定数 | 書体 | サイズ/行送り | ウェイト | 用途 |
|---|---|---|---|---|
| `northStar` | New York → ヒラギノ明朝 ProN | 20 / 27（lineSpacing 7） | Semibold / W6 | 北極星（付箋・入力欄） |
| `sheetTitle` | system | 17 / 24 | .semibold | 支度シートの問い |
| `lead` | system | 15 / 20 | .semibold | 支度の選択肢名 |
| `bodyStrong` | system | 14 / 20 | .semibold | 設定の選択中の行 |
| `body` | system | 14 / 20 | .regular | 一覧・設定・追加入力 |
| `voice` | system | 13 / 18 | .regular | banner |
| `voiceEmphasis` | system | 13 / 18 | .semibold | 寄り道の声かけ、完了メッセージ |
| `button` | system | 13 / 18 | .semibold | ボタン |
| `meta` | system | 12 / 16 | .medium | モード名・件数・from・手順番号・キー表記 |

- system は SF Pro＋ヒラギノ角ゴシック。北極星だけを明朝にして、「自分に宛てた1文」と補足情報を書体の段階で分ける。サイズ比は20/14で1.43倍と控えめにして、書体とウェイトで差を足す
- 明朝は `.cascadeList` で組む。`Font.system(design: .serif)` だけでは和文がゴシックに落ちる

```swift
static func northStarFont(size: CGFloat = 20) -> Font {
    let base = NSFont.systemFont(ofSize: size, weight: .semibold).fontDescriptor.withDesign(.serif)!
    let desc = base.addingAttributes([.cascadeList: [NSFontDescriptor(name: "HiraMinProN-W6", size: size)]])
    return Font(NSFont(descriptor: desc, size: size)!)
}
```

- 12pt 未満の文字は使わない。数字には `.monospacedDigit()` を付ける
- 行の省略は `.truncationMode(.tail)`。北極星は常駐で `lineLimit(2)`、展開で `lineLimit(4)`

### 3-6. 素材・影 `PolarisTheme.Material`

- 下地は `NSVisualEffectView(material: .popover, blendingMode: .behindWindow, state: .active)`。nonactivating パネルは `.followsWindowActiveState` だと常に灰色になるので、`.active` に固定する
- その上に `surface` を **92%** で重ねる（`surfaceOpacity = 0.92`）。壁紙の色がわずかに滲む程度にとどめ、文字のコントラストは地で保つ
- 内側に `hairline` 0.5pt の枠を付ける。角は `maskImage` の9-slice（capInsets = 16）で切る
- 影は `NSPanel.hasShadow = true` のシステム影だけにする。frame を変えたら `invalidateShadow()` を呼ぶ。SwiftUI の `.shadow` は使わない
- Reduce Transparency または Increase Contrast のときは素材を外し、`surface` を100%にする
- `--render-snapshots` は ImageRenderer が素材を描けないので、`surface` 100%で描く

## 4. モーション `PolarisTheme.Motion`

ループ・点滅・バウンスは使わない。達成時の演出は Reduce Motion を尊重する。

| 定数 | 遷移 | パラメータ | Reduce Motion |
|---|---|---|---|
| `expand` | ホバー展開 | `.spring(response: 0.32, dampingFraction: 0.9)`。追加行は opacity 0→1、0.18s easeOut、遅延0.06s | 高さは即時、中身は0.15s フェード |
| `collapse` | 折りたたみ | `.spring(response: 0.28, dampingFraction: 1.0)` | 即時 |
| `hoverDelay` / `leaveDelay` | 開くまで / 閉じるまで | 0.25s / 0.5s | 同じ |
| `voiceSwap` | 声の行の切り替え | crossfade＋y 4pt、0.2s easeOut | 0.15s フェード |
| `snap` | 隅へスナップ | `NSAnimationContext` 0.22s、`CAMediaTimingFunction(controlPoints: 0.2, 0.8, 0.2, 1)` | 即時 |
| `visibility` | 表示/非表示 | alphaValue 0.16s | 同じ |
| `sheetIn` | シートの出現 | 付箋の隅を起点に scale 0.96→1＋opacity、0.25s easeOut | 0.15s フェード |
| `sheetStep` | 支度のステップ移動 | x 24pt＋フェード、0.22s easeInOut | 0.15s フェード |

**ウィンドウの高さの変え方**: 伸ばすときは、先に panel の frame を新しい高さへ即時に広げ（スナップした隅を固定）、SwiftUI 側の背景の形と中身を spring で伸ばす。縮めるときは、spring が終わってから frame を縮める。frame 自体はアニメーションさせない。最後に `invalidateShadow()` を呼ぶ。

## 5. 文言

文体: 付箋とシートの文は**常体の短文**にする。句点はメッセージにだけ付け、ボタンには付けない。ボタンは動詞で終える。英字はアプリ名「Polaris」、MCP クライアント名、キー記号だけにする。

| 北極星が空 | 北極星を設定する |

### 設定

タブは作らず1画面を縦にスクロールする（幅480、高さは画面に収まる640まで、縦だけ伸び縮み）。まとまりごとに見出しを面の外に置き、中身を白い面（`GroupCard`、角丸10、hairline の縁）に載せる。行は左に名前と meta の補足、右に操作（`CardRow`、高さ44以上）、行の間に hairline。開く入口は、メニューバー・付箋の右クリックに加えて、展開した付箋の右下の歯車。

順に「表示」（付箋の地の透明度 0〜80%。閉じているときだけ効き、文字は薄くしない／達成したときの演出／演出の音）「モード」「ショートカット」「起動」（Mac にログインしたら開く）「AI との連携（MCP）」。ボタンは「モードを追加」「アプリを選ぶ…」「コマンドをコピー」。

モードは一覧（行 h32、選択中は 1.5pt ink の枠、右に meta で「既定 · 今日」）の下に、選んだ1件の編集欄だけを出す。編集欄は「名前」（20文字まで、空にしたら元に戻す）、「寄り道とみなすアプリ」（アプリ名＋［外す］、空なら「寄り道は知らせない」）と［アプリを選ぶ…］（/Applications から .app を複数選べる）、［このモードを削除］。既定のモードと今日のモードは削除ボタンを無効にし、その下に理由を ink2 で出す（「既定のモードは削除できない。日付が替わるとこのモードに戻る。」「今日使っているモードは削除できない。別のモードに替えてから消して。」）。ショートカットが衝突したときは「⌃⌥L はほかのアプリが使っている。別のキーを選んで。」と出す。

## 6. インタラクション

### パネル

- `NSPanel`、`styleMask = [.borderless, .nonactivatingPanel]`、`level = .floating`、`collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary]`、`isOpaque = false`、`backgroundColor = .clear`
- クリックしても前面アプリのフォーカスは奪わない。`makeKey()` するのはテキスト入力に入ったとき、または ⌃⌥O のときだけにする

### マウス

- 背景をドラッグすると移動する。離すと、パネル中心が属する象限の隅へスナップする。位置は「ディスプレイの UUID＋隅」で保存し、そのディスプレイがなければメイン画面の同じ隅に置く
- ホバーとクリックでの展開は展開の説明のとおり。ドラッグ中とクリック透過中は展開しない（透過中はつまみで開く）
- 開いた付箋のボタンや行にポインタが0.5秒止まると、押すと何が起きるかを吹き出しで出す（例: 歯車「設定を開く（…）」、✓「達成にして、次の控えを今日の北極星にする」、北極星「クリックで期限と控え・ダブルクリックで書き直す」）。対象の下に出し、下に余白がなければ上。左右は付箋の内側に収める。重なったら小さいほうの案内を出す。非アクティブでも出るよう、当たり判定はパネルが渡すポインタ位置で行う
- カーソルが付箋から外れたら、クリックで開いたときも含めて0.5秒後に必ず畳む。残すのは書いている途中・キーボードで操作中・掴んでいる最中だけ。mouseExited は窓の伸び縮みのあとに来ないことがあるので、0.25秒ごとにカーソルの位置も直接見る（メニューを開いている間は見ない）
- 右クリックで行メニューを出す。背景で右クリックしたときはメニューバーと同じ操作を出す

- 開いた付箋のモード表示を押すとモードを替えられる。北極星をクリックすると一覧、ダブルクリックするとその場で編集する。右クリックと VoiceOver から達成・手放す操作に届く。期限と予約は一覧で設定する。

### クリック透過中の⌥

- 透過中だけ 0.1秒ごとのタイマーで `NSEvent.modifierFlags.contains(.option)` と `NSEvent.mouseLocation` がパネル内にあるかを見る。両方が真のあいだだけ `ignoresMouseEvents = false` にする。グローバルなイベント監視は使わないので、アクセシビリティ権限はいらない

### グローバルショートカット

Carbon `RegisterEventHotKey` で登録する。設定から変えられる。

| キー | 動作 |
|---|---|
| ⌃⌥P | 北極星のクイック編集 |
| ⌃⌥L | 北極星の一覧 |
| ⌃⌥O | 付箋を操作する（展開を固定し、key にする） |
| ⌃⌥H | 付箋を隠す / 表示する |
| ⌃⌥T | クリック透過を切り替える |


### 付箋が key のとき

↑↓ または Tab で操作対象を移動し、⏎ / Space で実行する。⌘Z で達成を取り消し、⎋ で key を外して直前のアプリを `activate` する。

### 非表示

- 「付箋を隠す」: 戻すまで隠れたまま。寄り道のときは寄り道時の簡易パネルだけ出す
- 「15分だけ隠す」: 時間が来たら自動で戻る。寄り道も出さない
- ロールオーバーすると表示に戻す。隠しているあいだもメニューバーの1行目で北極星が見える
- 画面共有中の自動非表示はしない（仕様にない）

## 7. アクセシビリティ

### VoiceOver

| 要素 | ラベル / 値 | 特性・操作 |
|---|---|---|
| パネル | 「Polaris。北極星、{northStar}。{mode}」／値「展開中」「たたんでいる」 | `children: .contain`、窓の subrole は floatingWindow、窓の custom action に「展開する」「たたむ」 |
| モード名 | 「モード、{mode}。押すと切り替える」 | ポップアップメニュー。モードの一覧から選ぶ |
| モード表示の行の右側 | 「付箋の開閉」／値「展開中」「たたんでいる」 | ボタン。既定操作（AXPress）で開閉、ヒント「押すと付箋を展開する／たたむ」、操作「展開する」「たたむ」。クリックでも開閉する行なので見た目は変えない |
| 北極星 | 「北極星、{text}」／空:「北極星を設定する」 | `.isHeader`、操作「編集」「達成した」「手放す」。空のときはボタン（ヒント「押すと今日の北極星を書ける」） |
| 達成 | 「達成した」 | ボタン。今日が空で控えがあれば「これにする」 |
| 北極星の一覧 | 「北極星の一覧」 | ボタン。控えを足す＋にもラベルを付ける |
| モード glyph | 読ませない | `accessibilityHidden(true)`（名前は文字で読む） |
| つまみ | 「付箋のつまみ」 | ボタン。押すと開閉 |

声の行が替わったら `NSAccessibility.post(element:notification: .announcementRequested, userInfo:)` で1回だけ読み上げる。寄り道は priority medium で「今日は{mode}。{App}が前面にある。北極星、{text}」、banner は low、達成は「{title}を達成した。次の北極星は{next}」。

### Increase Contrast / Differentiate Without Color / Reduce Transparency / Reduce Motion

- Increase Contrast: 素材を外し `surface` を100%にする。`ink2` と `star` を `HighContrast` に差し替え、外周に `HighContrast.border` を付ける。つまみの縁にも `HighContrast.border` を付ける
- Reduce Transparency: 素材を外す
- Reduce Motion: 4章の表のとおり

### キーボードだけでの操作

- ⌃⌥O と ⌃⌥P / ⌃⌥L から、すべての操作に届く。隅の移動はメニューの「付箋を置く隅」でできる
- フォーカスリングは `star` の2pt、外側に2pt 離し、角丸は要素と同じにする。`focusable()` にして自前で描き、すべての操作要素に出す
- 付箋の Tab / ↑↓ の順: 北極星 → 達成またはこれにする（ある場合）→ 一覧 → 控えに足す（空きがある場合）→ 声の行のボタン。⏎ / Space で実行する。達成ボタンのフォーカス名 `.starQueue` と `performStarQueueAction` は維持する。
- 寄り道が出ているときは、⌃⌥O ひとつで「{App}を隠す」にフォーカスが入る
- 支度シート: 1/2/3 または ↑↓ でモードを選ぶ、Tab で主ボタンへ、⏎ で次へ、⌘← で戻る。開いたら最初の操作要素にフォーカスを置く。選択肢の右の数字はキーキャップ（16×16 r4 1pt hairline）で描く

### サイズ

文字は12pt以上（本文14pt）、当たり判定は24×24以上（付箋の行は28、シートの行は36〜56）。

## 付記: `--render-snapshots` の対象

`--render-snapshots <dir>` でライト／ダークの主要状態を書き出す。一部の状態はコントラスト強調とモード違いも対象。`celebration-early` と `celebration-mid` はライトのみ。メニューバーアイコンは明暗を1枚に収める。素材は不透明のsurfaceで代用する。

`collapsed`, `collapsed-2line`, `expanded`, `empty-northstar`, `empty-expanded`, `queue-without-today`, `morning-1`, `morning-2`, `morning-2-filled`, `detour`, `detour-keyboard`, `detour-hidden`, `banner`, `banner-expanded`, `banner-mode-changed`, `clickthrough`, `clickthrough-hover`, `hint-settings`, `quick-edit`, `expanded-star-queue`, `star-queue-add`, `star-achieved`, `stars-window`, `settings`, `settings-reading`, `settings-custom`, `celebration-early`, `celebration-mid`, `menubar-icon`, `menubar-icon-hidden`。
