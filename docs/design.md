# Polaris デザイン仕様「一点の光」

前提: `docs/product.md`（データモデル・ルール・構成）。この文書は見た目と振る舞いだけを決める。仕様の意図は変えない。

## 0. 審査

| 案 | 問題解決 | 邪魔にならなさ | 7軸 | AIっぽさの無さ | 実現性 | 平均 |
|---|---|---|---|---|---|---|
| 1 paper（静かな付箋） | 8 | 8 | 8 | 7 | 8 | 7.8 |
| 2 ネイティブのピル | 7 | 7 | 7 | 6 | 6 | 6.6 |
| **3 star（一点の光）** | **9** | **9** | **8** | **9** | **7** | **8.4** |

- **3を土台にした理由**: 色の付いた点が本命の横に1つだけある。これで「光っている行＝いまやること」が読まなくても伝わり、0.3秒で本命を思い出せる。一時的なメッセージ（寄り道・banner・取り消し・4件目）は最下段の「声の行」1か所に優先順位付きで出すので、付箋の形が揺れない
- **案1から移植**: 寄り道の「5分だけ」、4件目の「入れ替える…」、隠しているあいだの簡易寄り道表示、明朝に New York を組み合わせる書体カスケード、全部完了の「今日はここまで」、メニューバー1行目に北極星を出すこと
- **案2から移植**: 展開を画面の中心側へ向けること、クリックで展開を固定すること、⌥を押しているあいだだけクリック透過を解除すること、「あとで」件数の numericText、クイック編集パネル
- **採らなかったもの**: 案1のクリーム地（AI_SLOP 2章に抵触するため、無彩色の `surface` にした）。案2の全面ティント（薄色塗り）、最大サイズ固定パネル＋自前 hit-test（壊れやすい）、17対13pt の弱い階層。案3の「支度シートを付箋そのものが変形して出す」方式（nonactivating パネルでは key の扱いが複雑になるので、別パネルにした）

## 1. コンセプト

- 付箋は無彩色。色で光るのは**本命の横にある直径8ptの点ひとつ**だけ
- 目線は、明朝の大きな1文（北極星）から光る1行（本命）へ流れる。それ以外は明度を落として沈める
- 星の比喩は「点」と「名前」だけで表す。星形・きらめき・夜空・発光は描かない
- 形は動かさない。変わるのは最下段の「声の行」の1行と、光の点だけ

| 問題 | 打ち手 |
|---|---|
| 本命を忘れる | 常駐時に見えるのは北極星・本命・モードの3つだけ。2・3件目は展開したときだけ ink2 で出る。あとで（6〜10位）は件数しか見えない |
| 寄り道する | 付箋の大きさ・位置は変えない。声の行が「読書の日。戻る？」に替わり、光の点から波紋が1回だけ広がる。ボタンで寄り道先のアプリを隠せる |
| うるさい | 常時動くものはない。ループ・点滅・バウンスもない。クリックしても前面アプリのフォーカスを奪わない |

### 用語集（UI ではこの語だけを使う）

| 語 | 指すもの | 使い方 |
|---|---|---|
| 北極星 | `Day.northStar` | 「北極星を書き換える」 |
| 本命 | `now[0]` | 「本命にする」 |
| いま | `now` | 「いまに入れる」「いまは3件で満杯」 |
| あとで | `later` | 「あとでに送る」「あとで 7」 |
| 済 | `done` | 件数表示だけに使う「済 2」。動詞は「完了にする」 |
| 寄り道 | avoidApps が前面に来ること | 内部用語。UI には出さない |
| 声の行 | 付箋の最下段の1行 | 内部用語 |

## 2. 状態ごとのレイアウト

### 共通寸法

- 付箋の幅は `Metrics.noteWidth = 304` で固定。内側の余白は上下16、左右20（内容幅264）。角丸は16
- 縦は3段。[北極星] → 12 → [本命] → 16 → [声の行]
- スナップ先は `visibleFrame` の四隅から16pt内側
- 高さは中身に合わせて変える。**伸びる方向は画面の中心側**にする（下の隅なら上へ、上の隅なら下へ）。スナップしている隅を固定点にする
- 光の点は本命行の x-height 中央に置く。本命テキストは x=18 から始まる（点8＋間隔10）。北極星は x=0 から始めて、点の分だけ左へ張り出す「ぶら下げ」にする

### 2-1. 常駐（collapsed）

```
┌────────────────────────────────────┐ w304 / r16
│ ↕16                                │
│  決済APIの移行を今日中に              │ northStar 明朝W6 20/27, 最大2行, 末尾…
│  本番へ出す                          │
│ ↕12                                │
│  ●  レビュー指摘を直す                │ 点⌀8 star + 10 + taskLead 14/20 semibold, 1行…
│ ↕16                                │
│  ▣ 仕事の日                          │ 声の行: glyph 12pt(tint) + 6 + meta 12pt medium ink2
│ ↕16                                │
└────────────────────────────────────┘ h = 16+54+12+20+16+16+16 = 150（北極星1行なら123）
```

- 2・3件目、あとでの件数、済の件数は**出さない**
- 本命の点はクリックで完了できる（当たり判定は24×24）

### 2-2. ホバー展開（expanded）

ポインタが250ms留まると開き、離れて500ms経つと閉じる。**クリックすると展開を固定**し、もう一度クリックするか ⎋ で解除する。テキスト入力中は閉じない。

```
┌────────────────────────────────────┐
│  決済APIの移行を今日中に              │ 北極星 最大4行（省略なしで全文）
│  本番へ出す                          │
│ ↕12                                │
│  ◉  レビュー指摘を直す          ⋯     │ ホバー行: 点が⌀16のリング付き完了ボタンに変わる
│ ↕8                                 │
│  ○  CIの遅いテストを分ける      ⋯     │ task 14/20 regular ink2, リング⌀8 線1pt ink2
│ ↕8                                 │
│  ○  採用面接の評価を書く              │
│ ↕12                                │
│  ＋ 追加                             │ button 13pt semibold ink2 → 押すとその場で入力欄
│ ↕16  ─ 0.5pt hairline（内容幅いっぱい）─ │
│ ↕12                                │
│  あとで 7                      ›     │ meta 12pt medium ink2（付箋でいちばん静かな段）, 押すとその場で開く
│ ↕12                                │
│  ▣ 仕事の日                    済 2  │ 声の行
└────────────────────────────────────┘
```

- 行の見た目の高さは20、行間は8。当たり判定は1行28（上下4ずつ広げる）
- 行にホバーすると `hoverFill` を敷く（角丸8、左右に8はみ出す）。右端に「⋯」（24×24）を出す。メニューは「本命にする / あとでに送る / 名前を変える / 削除」
- 行はドラッグで並べ替えられる。先頭に置いたものが本命になり、光の点がその行へ移る
- **あとでを開く**: 「あとで 7 ›」が「⌄」に回り、その下に最大5行（各32）のスクロール領域が開く。リスト全体を `hoverFill` の面（r8）に収め、各行は voice 13pt ink2 で左に8字下げする。「いまに入れる」はホバー中かキーボードでフォーカスした行にだけ出す。いまが満杯のときはボタンを出さず、見出しを「あとで 7・いまは満杯」（ink2）に変える。付箋を閉じたら、あとでも閉じる（次に開くときは閉じた状態から始める）

### 2-3. 北極星が空

```
│  今日の北極星は、まだない              │ northStar 明朝W6 20pt, ink（薄くしない）
│ ↕12                                │
│  →  朝の支度を始める                  │ taskLead のボタン。→ は arrow.right 11pt ink（リングはタスク専用なので使わない）
│ ↕16                                │
│  ▣ 仕事の日                          │
```

- 北極星は空で、いまに項目があるとき: 1段目は同じ文言にし、2段目は通常どおり本命を出す
- 北極星があって、いまが空のとき: 2段目を「＋ 本命を追加する」ボタンにする（＋ は 12pt semibold ink、点と同じ x=0〜8）
- ロールオーバー直後と初回起動時は、これに加えて朝の支度シートを自動で出す（2-4）

### 2-4. 朝の支度シート

- 付箋とは別の `NSPanel`（borderless、key になれる、`.floating`）。幅は `Metrics.sheetWidth = 400`、余白24、角丸18。付箋の隅を起点に、画面中心側へ出る
- 自動で出したときは key にしない（前面アプリの入力を奪わない）。クリックするか、メニューバーから開いたときに key にする
- 1画面に1ステップだけ出す

```
Step 1
┌──────────────────────────────────────────────┐
│  朝の支度                           1 / 3     │ button 13 semibold ink / meta ink2
│ ↕16                                          │
│  今日はどんな日？                             │ sheetTitle 17/24 semibold
│ ↕12                                          │
│  ┌──────────────────────────────────────┐   │ 選択肢 h56, r10。選択中は1.5pt ink の枠（塗らない）
│  │ ▣  仕事の日                        1 │   │ glyph 16 tint / lead 15 semibold / meta（キー）
│  │    寄り道は知らせない                 │   │ meta ink2
│  └──────────────────────────────────────┘   │
│  │ ▤  読書の日                        2 │   │ 補足: Slack・Claude を寄り道として知らせる
│  │ ◌  休む日                          3 │   │
│ ↕24                                          │
│                        [ 北極星を書く ⏎ ]     │ 主ボタン h32 r8 地 ink / 文字 surface
└──────────────────────────────────────────────┘

Step 2
│  朝の支度                           2 / 3     │
│  今日いちばん大事なことを1文で               │ sheetTitle
│  ┌──────────────────────────────────────┐   │ 入力欄 r6, 1pt hairline, 明朝W6 20pt, 高さ自動（最大3行）
│  │ 例: 決済APIの移行を本番に出す          │   │ placeholder ink2
│  └──────────────────────────────────────┘   │
│  1文で書けないなら、まだ絞れていない。         │ meta ink2（常に出す）
│  昨日の北極星を引き継ぐ                       │ リンクボタン 13pt（昨日の分があり、未達のときだけ）
│  [ 戻る ]                [ いまの3件を選ぶ ⏎ ]  │

Step 3
│  朝の支度                           3 / 3     │
│  いまやることを3つまで                        │ sheetTitle
│  最初に選んだものが本命になる                  │ meta ink2
│  ① レビュー指摘を直す             昨日から   │ 行h36。選んだ順の番号をリング⌀20に入れる。①だけ star で塗る
│  ② CIの遅いテストを分ける                     │
│  ○ 採用面接の評価を書く     Claude Code から  │ 出所 meta ink2
│  ○ …（最大6行、スクロール）                   │ 3件選ぶと未選択の行は無効（文字は ink2 のまま）
│  ＋ 新しく書く                                │
│  [ 戻る ]                 [ この2件で始める ⏎ ] │ 0件なら「北極星だけで始める」
```

- 既定は `Day.mode`（ロールオーバーで既定モードに戻った値）を選んでおく
- Step 2 は空のままでも止めない。ボタンは無効にせず、名前を「北極星なしで進む」に変える
- あとでが空なら、Step 3 は「あとでは空。新しく書くか、北極星だけで始めよう。」と「＋ 新しく書く」にし、入力欄にフォーカスを置く
- ✕ は置かない。⎋ で閉じ、そこまでの選択は保存する（モードだけ選んだ場合も有効）

### 2-5. 本命の完了と繰り上がり（主役の動き）

```
t=0      ●  レビュー指摘を直す      点が ✓（star, 10pt semibold）に変わる 120ms
t=120    ✓  ───────────           取り消し線を左から右へ描く 200ms
t=320    行が上へ8pt動きながら消える 220ms。2件目が上へ詰める
t=320    ○→●  光の点が matchedGeometry で次の行へ移る。文字は ink2 regular → ink semibold
声の行:   「完了にした。」＋［取り消す］を5秒出す（⌘Z でも取り消せる）
```

- 常駐中に完了した場合（MCP やキーボードから）: 本命の行が上へ抜け、新しい本命が下から入る。点も同じ動きをする
- いまが空になったら 2-10 へ移る

### 2-6. 寄り道を検知したとき

付箋の大きさ・位置・不透明度・北極星は**変えない**。

```
│  『遅いインターネット』を3章まで読む    │
│ ↕12                                │
│  ●  2章の要点を3行でメモ              │ 点から 1pt リングが ⌀8→28 に一度だけ広がって消える
│ ↕16                                │
│  読書の日。戻る？ [Slackを隠す] [5分]  │ 声の行は1行（高さ16）のまま。voiceEmphasis ink
│                                    │ smallButton h24 r6 は上下にはみ出す。1つ目は ink の枠、2つ目は文字だけ
```

- 「{App}を隠す」は `NSRunningApplication.hide()` を呼ぶだけにする。終了もブロックもしない。隠すと直前のアプリが前面に戻る
- 「5分だけ」はそのアプリについて5分間出さない（仕様の5分抑制を、自分で選べるようにしたもの）
- 何も押さなくても、前面アプリが変わるか12秒経ったら元の声の行に戻す
- 同じアプリで連続して出すのは5分に1回まで（仕様どおり）
- **⌃⌥H で隠しているとき**: 付箋と同じ隅に、北極星と声の行だけの簡易パネル（幅304、ボタンなし、クリック透過）を12秒出す。見たくない日ほど寄り道しやすいので、ここは止めない
- **「15分だけ隠す」中**: 何も出さない（休憩を自分で選んだため）
- クリック透過中: 声の行だけ替え、ボタンは出さない

### 2-7. MCP からの banner

声の行に出す。優先順位は **寄り道 > 取り消し・4件目 > banner > モード表示**。同時に出すのは1件だけで、下位のものは上位が消えるまで待つ。

```
│  ●  レビュー指摘を直す                │
│ ↕16                                │
│  PR終わったよ、本命に戻ろう · Claude… × │ 常駐中は1行。text は ink、「· {client}」は ink2、末尾を省略
│  （展開中だけ 全文2行 ＋「{client} から」meta ink2）      │
```

- 北極星より上には出さない。背景も塗らない。バッジ・色・音も付けない
- × は20pt、当たり判定24×24。`expiresAt` が来るか × を押したら、モード表示に戻す
- banner が出ているあいだにモードが替わったら（メニュー・支度・MCP のどれでも）、「取り消し・4件目」と同じ段で「{glyph} {mode label}に切り替えた」を4秒出してから banner に戻す。glyph と位置はモード表示と同じにし、文字だけ ink にする。モードを常設する2つ目の場所は作らない（付箋を3段から増やさない、声の行を1か所に保つため）。モード表示が見えているときは行そのものが替わるので出さない

### 2-8. クリック透過中

```
│  決済APIの移行を今日中に本番へ出す     │ パネル全体 alpha 0.72
│  ●  レビュー指摘を直す                │
│  ▣ 仕事の日                   ⊘     │ cursorarrow.slash 12pt ink2
```

- `ignoresMouseEvents = true`。ホバーしても展開しない
- **⌥を押しているあいだだけ触れる**ようにする。アイコンを ink にし、alpha を1.0に戻す（判定方法は6章）
- 解除は ⌃⌥T かメニューバー

### 2-9. 4件目が「あとで」に送られたとき

```
│  「議事録を整える」はあとでへ [入れ替える…] │ 1行。title だけ末尾を省略。MCP は収まれば「（{client} から）」meta ink2
│                                    │ 6秒出す（ホバー中は消さない）
```

- MCP から入って溢れたものは、状態の `lastOverflow`（source が `mcp:` で始まり、30秒以内のもの）を見て同じ知らせを出す。付箋での操作は操作した側で出すので二重にしない。起動直後の読み込みでは出さない
- 展開中なら「あとで 7 → 8」の数字を `numericText` で切り替えるだけにする。いまの3行は動かさない
- 「入れ替える…」を押すと展開を固定し、2・3件目の右に「入れ替える」（button ink2、ホバーで ink）を出す。本命とは入れ替えない（本命と替えたいときは行メニューの「本命にする」）。声の行は「入れ替える行を選ぶ ［やめる］」にする（⎋ でもやめられる）。選んだ項目があとでの先頭へ、追加した項目がいまの末尾へ入る。自動では入れ替えない

### 2-10. 全部完了した日（now が空で done ≥ 1）

```
│  決済APIの移行を今日中に本番へ出す     │ 北極星はそのまま（取り消し線は引かない）
│ ↕12                                │
│  ✓  今日の分は済んだ                  │ ✓ star 10pt semibold / taskLead ink
│ ↕16                                │
│  ▣ 仕事の日                   済 3  │
```

- 展開すると「今日はここまで」（枠付き）だけを出す。あとでから選びたいときは「あとで n ›」から開く。付箋のほうから次のタスクを勧めることはしない（あとでが空のときだけ、文字だけの「＋ 追加」を左に出す）
- 全部完了の日は、常駐中も声の行に「済 n」を出す
- 「今日はここまで」を押すと、声の行だけの1行（`▣ 仕事の日・今日はここまで`、高さ44）にする。ロールオーバーで元に戻る
- 紙吹雪などの祝いの演出は入れない

### 2-11. クイック編集パネル（⌃⌥P / ⌃⌥N）

```
┌──────────────────────────────────────────────┐ w400 r14 余白20
│  北極星                                       │ meta ink2
│  決済APIの移行を今日中に本番へ出す              │ 明朝W6 20pt 入力欄
│ ↕12                                          │
│  追加                                         │ meta ink2
│  やることを1行で                               │ task 14pt 入力欄
│  いまに入れる（残り1枠）                        │ meta ink2 / 満杯なら「あとでに入れる（いまは3件で満杯）」
│ ↕16                                          │
│  ⏎ 保存する   ⌥⏎ あとでに入れる   ⎋ 閉じる       │ meta ink2（常に出す）
└──────────────────────────────────────────────┘
```

- 付箋の隅から画面中心側へ出す。⌃⌥P なら北極星に、⌃⌥N なら追加にフォーカスする。閉じたら直前のアプリへフォーカスを返す

## 3. デザイントークン

すべて `Sources/PolarisApp/Theme/PolarisTheme.swift` の `enum PolarisTheme` に置く。色は `NSColor(name:dynamicProvider:)` でライトとダークを切り替え、`Color(nsColor:)` で使う。Asset Catalog は使わない。

### 3-1. 色 `PolarisTheme.Palette`

| 定数 | Light | 対surface | Dark | 対surface | 用途 |
|---|---|---|---|---|---|
| `surface` | #F4F5F6 | – | #1D1E22 | – | 付箋・シートの地 |
| `ink` | #1C1E22 | 15.29 | #F1F1F3 | 14.76 | 北極星・本命・本文・主ボタンの地 |
| `ink2` | #4B5058 | 7.43 | #AEB2BA | 7.83 | 沈める行・補足。**これより薄い文字色は作らない** |
| `hairline` | ink 10% | – | #FFFFFF 10% | – | 区切り線・パネル内枠 0.5pt |
| `hoverFill` | ink 6% | – | #FFFFFF 8% | – | 行ホバー |
| `pressFill` | ink 10% | – | #FFFFFF 12% | – | 押下 |
| `star` | #A36F0C | 3.98（非テキスト） | #F0C24E | 9.94 | 光の点・完了チェック・フォーカスリングの3か所だけ。文字には使わない |
| `danger` | `NSColor.systemRed` | – | 同 | – | 「削除」と保存失敗だけ |

モードのティント `PolarisTheme.Palette.Mode`（`Mode.tint` の文字列 → 定数。未知の値は `slate`）。**glyph にだけ使う**。地は塗らない。

### 3-6. 素材・影 `PolarisTheme.Material`

- 下地は `NSVisualEffectView(material: .popover, blendingMode: .behindWindow, state: .active)`。nonactivating パネルは `.followsWindowActiveState` だと常に灰色になるので、`.active` に固定する

## 4. モーション `PolarisTheme.Motion`

主役の動きは「光が次の行へ移る」1か所だけ。ループ・点滅・バウンスは使わない（damping はすべて0.88以上）。同時に動かすのは1系統までにし、完了の動き中に来た banner は完了が終わってから出す。

| 定数 | 遷移 | パラメータ | Reduce Motion |
|---|---|---|---|
| `expand` | ホバー展開 | `.spring(response: 0.32, dampingFraction: 0.9)`。追加行は opacity 0→1、0.18s easeOut、遅延0.06s | 高さは即時、中身は0.15s フェード |
| `collapse` | 折りたたみ | `.spring(response: 0.28, dampingFraction: 1.0)` | 即時 |
| `hoverDelay` / `leaveDelay` | 開くまで / 閉じるまで | 0.25s / 0.5s | 同じ |
| `checkFill` | 点→✓ | 0.12s easeOut | 同じ |
| `strike` | 取り消し線 | `trim` 0.2s linear | 即時で線を出す |
| `rowExit` | 行の退場 | 0.22s easeIn、y −8 | 0.15s フェード |
| `promote` | 光の移動・繰り上がり | `matchedGeometryEffect`、`.spring(response: 0.4, dampingFraction: 0.9)` | 光は移動させず、次の行で即時に点ける |
| `ripple` | 寄り道の波紋 | 1pt リング ⌀8→28、opacity 0.6→0、0.9s easeOut、**1回だけ** | 出さない |
| `voiceSwap` | 声の行の切り替え | crossfade＋y 4pt、0.2s easeOut | 0.15s フェード |
| `count` | あとでの件数 | `.contentTransition(.numericText())` 0.2s | 即時 |
| `laterDisclose` | あとでを開く | `.spring(response: 0.3, dampingFraction: 0.9)`、シェブロン90° | 即時 |
| `snap` | 隅へスナップ | `NSAnimationContext` 0.22s、`CAMediaTimingFunction(controlPoints: 0.2, 0.8, 0.2, 1)` | 即時 |
| `visibility` | 表示/非表示 | alphaValue 0.16s | 同じ |
| `sheetIn` | シートの出現 | 付箋の隅を起点に scale 0.96→1＋opacity、0.25s easeOut | 0.15s フェード |
| `sheetStep` | 支度のステップ移動 | x 24pt＋フェード、0.22s easeInOut | 0.15s フェード |
| `allDone` | 点→✓（全部完了） | scale 0.6→1、`.spring(response: 0.3, dampingFraction: 0.9)` | 即時 |

**ウィンドウの高さの変え方**: 伸ばすときは、先に panel の frame を新しい高さへ即時に広げ（スナップした隅を固定）、SwiftUI 側の背景の形と中身を spring で伸ばす。縮めるときは、spring が終わってから frame を縮める。frame 自体はアニメーションさせない。最後に `invalidateShadow()` を呼ぶ。

## 6. インタラクション

### パネル

- `NSPanel`、`styleMask = [.borderless, .nonactivatingPanel]`、`level = .floating`、`collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary]`、`isOpaque = false`、`backgroundColor = .clear`
- クリックしても前面アプリのフォーカスは奪わない。`makeKey()` するのはテキスト入力に入ったとき、または ⌃⌥O のときだけにする

### マウス

- 背景をドラッグすると移動する。離すと、パネル中心が属する象限の隅へスナップする。位置は「ディスプレイの UUID＋隅」で保存し、そのディスプレイがなければメイン画面の同じ隅に置く
- ホバーとクリックでの展開は 2-2 のとおり。ドラッグ中とクリック透過中は展開しない
- 点・リングをクリックすると完了。行のテキストをダブルクリックするとその場で名前を変える。北極星をダブルクリックするとその場で編集する（明朝のまま。⏎ で確定、⎋ で取り消し）
- 右クリックで行メニューを出す。背景で右クリックしたときはメニューバーと同じ操作を出す

### クリック透過中の⌥

- 透過中だけ 0.1秒ごとのタイマーで `NSEvent.modifierFlags.contains(.option)` と `NSEvent.mouseLocation` がパネル内にあるかを見る。両方が真のあいだだけ `ignoresMouseEvents = false` にする。グローバルなイベント監視は使わないので、アクセシビリティ権限はいらない

### グローバルショートカット

Carbon `RegisterEventHotKey` で登録する。設定から変えられる。

| キー | 動作 |
|---|---|
| ⌃⌥P | クイック編集（北極星にフォーカス） |
| ⌃⌥N | クイック編集（追加にフォーカス） |
| ⌃⌥O | 付箋を操作する（展開を固定し、key にする） |
| ⌃⌥H | 付箋を隠す / 表示する |
| ⌃⌥T | クリック透過を切り替える |

誤爆を避けるため、グローバルな「本命を完了」は置かない。

### 付箋が key のとき

↑↓ で行を移動、Space で完了、⌘↑ で本命にする、⌫ であとでに送る、⌘⌫ で削除、⏎ で名前を変える、L であとでを開閉、⌘Z で取り消す、⎋ で key を外して直前のアプリを `activate` する（`NSApp.hide` は使わない）。Tab の順は 北極星 → いまの各行 → 追加 → あとで。

### 非表示

- 「付箋を隠す」: 戻すまで隠れたまま。寄り道のときは 2-6 の簡易パネルだけ出す
- 「15分だけ隠す」: 時間が来たら自動で戻る。寄り道も出さない
- ロールオーバーすると表示に戻す。隠しているあいだもメニューバーの1行目で北極星が見える
- 画面共有中の自動非表示はしない（仕様にない）

### VoiceOver

| 要素 | ラベル / 値 | 特性・操作 |

| 2・3件目 | 「いまの{n}件目、{title}」 | ボタン。既定操作で完了。操作「本命にする」「完了にする」「あとでに送る」 |
| 点・リング | 「{title}を完了にする」 | ボタン。完了後は `accessibilityValue("完了")` |
| あとで | 「あとで、{n}件」 | ボタン、展開状態を持つ |
| モード glyph | 読ませない | `accessibilityHidden(true)`（名前は文字で読む） |
| 透過中アイコン | 「クリック透過中。⌃⌥T で戻す」 | – |

声の行が替わったら `NSAccessibility.post(element:notification: .announcementRequested, userInfo:)` で1回だけ読み上げる。寄り道は priority medium で「今日は{mode}。{App}が前面にある。北極星、{text}」、banner は low、完了は「{title}を完了にした。次の本命は{next}」。

### Increase Contrast / Differentiate Without Color / Reduce Transparency / Reduce Motion

- Increase Contrast: 素材を外し `surface` を100%にする。`ink2` と `star` を `HighContrast` に差し替え、外周に `HighContrast.border` を付け、光の点に1pt の ink リングを重ねる。クリック透過の alpha は0.9にする
- Differentiate Without Color: 本命の点の左に `▸`（meta, ink）を足す
- Reduce Transparency: 素材を外す
- Reduce Motion: 4章の表のとおり

### キーボードだけでの操作

- ⌃⌥O と ⌃⌥P / ⌃⌥N から、すべての操作に届く。隅の移動はメニューの「付箋を置く隅」でできる
- フォーカスリングは `star` の2pt、外側に2pt 離し、角丸は要素と同じにする。`focusable()` にして自前で描き、すべての操作要素に出す
- 付箋の Tab / ↑↓ の順: 北極星 → いまの各行 →（入れ替え中なら2・3件目の「入れ替える」）→ 追加（全部完了ならその操作）→ あとで →（開いていれば）あとでの各行 → 声の行のボタン（左から）。⏎ と Space でそのボタンを押す。あとでの行は ⏎ / Space で「いまに入れる」、⌘⌫ で削除
- 寄り道が出ているときは、⌃⌥O ひとつで「{App}を隠す」にフォーカスが入る
- 支度シート: 1/2/3 または ↑↓ でモードを選ぶ、Tab で主ボタンへ、⏎ で次へ、⌘← で戻る、Step 3 は ↑↓＋Space で選ぶ。開いたら最初の操作要素にフォーカスを置く。選択肢の右の数字はキーキャップ（16×16 r4 1pt hairline）で描く

### サイズ
